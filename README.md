# Yari App 🌟

تطبيق دردشة صوتية اجتماعي — مستوحى من الأسلوب البصري لـ Hapi Ludo.

## الملفات
- `logo/` — شعار SVG، أيقونة التطبيق، أداة تصدير PNG
- `ui/` — شاشات واجهة التطبيق الكاملة (HTML+CSS)

## الشاشات
1. الشاشة الرئيسية (`ui/index.html`)
2. غرفة الصوت (`ui/room.html`)
3. الملف الشخصي (`ui/profile.html`)
