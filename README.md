# MEZO - Social Voice Chat Visual Identity

This repository contains the full visual identity and UI prototypes for **MEZO**, a social voice chat application.

## 📁 Folder Structure

- `logo/`: Contains the application branding assets.
  - `logo.svg`: Main application logo (512x512).
  - `app-icon.svg`: Store icon (1024x1024).
  - `logo-export.html`: Tool to export SVGs to PNG.
- `ui/`: Contains the mobile-first UI prototypes.
  - `index.html`: Main discovery screen.
  - `room.html`: Voice chat room interface.
  - `profile.html`: User profile and achievements.

## 🎨 Design Language

- **Primary Colors**: Blue (#1a6fd4), Gold (#FFD700).
- **Typography**: Fredoka One (Headings), Tajawal (Arabic Content).
- **Style**: Playful, 3D, and energetic with vibrant gradients and cartoon elements.

## 🚀 How to use

Simply open any of the `.html` files in your browser to view the prototypes. No server is required.
To export the logo as PNG, open `logo/logo-export.html`.
